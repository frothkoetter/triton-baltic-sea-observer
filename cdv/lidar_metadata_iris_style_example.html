Baltic LiDAR vessel simulation catalog

Each row is one simulated LAS scene from NiFi LidarSimulator: center position, ASPRS classification code, vessel identity, and object-store path to the point cloud.

Simulated vessel families in this stream:

  • Merchant: oil_tanker, gas_tanker, container_ship, ferry, sailing
  • Naval silhouettes: corvette, frigate, submarine, landing_ship
  • Unclassified contacts: classification 0 (vessel_name / vessel_type undefined)
